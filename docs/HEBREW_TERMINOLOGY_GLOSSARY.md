# Hebrew Floor Terminology Glossary — Working Reference

**Purpose:** Canonical Hebrew translations for IL flooring technical terminology. Used by both iMac + MacBook Claude sessions for consistent vocabulary across translated pages. Targeted at the designer / architect / specifier / contractor audience — technical Hebrew register, not consumer-marketing Hebrew.

**Status:** Working draft 2026-05-29. Owner review required for production use — see uncertain entries marked ⚠️.

**Convention:** Keep brand names + standard codes in original Latin script (EN 13501-1, Sikafloor, ASTM F2170). Wrap in `<span dir="ltr">...</span>` when embedded in Hebrew paragraph for correct bidi rendering.

## Editing notes for translator

1. **Mixed-direction handling.** When embedding English standard code (EN 13501-1, ASTM F2170, R11, ₪480/m², Sikafloor PurCem HM-22), wrap in `<span dir="ltr">...</span>` for correct bidi rendering. The `he.css` `[dir="ltr"]` rule isolates these spans.

2. **Numerals.** Hebrew numerals (one, two, three) follow Western 1, 2, 3 — no separate Hebrew script numerals in modern usage. Currency symbol position: "₪ 480" reads as "480 ₪" in RTL flow.

3. **Brand-name capitalisation.** Keep manufacturer brand names in original Latin. Mixed-script paragraphs are normal in IL technical writing.

4. **Audience tone.** Designer/architect register — formal but accessible. Avoid colloquialisms. Use technical vocabulary consistently per this glossary.

5. **Updates.** When translator encounters a term not in this glossary, add to a "pending" section at bottom and flag for owner review.

6. **Source consistency.** Source EN page is authoritative for technical facts; Hebrew is translation, not creative paraphrase. If translation produces ambiguity, prefer literal-with-flag.
