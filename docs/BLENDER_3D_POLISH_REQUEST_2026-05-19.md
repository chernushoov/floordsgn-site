## Открытые правки (низкий приоритет, не блокируют прод)

### A. Фаска (bevel) на гранях плиты

Все слои сейчас — простые boxes (24 вершины). Top и Layers выглядят слишком «техническими», как 3D-mockup без проработки.

**Что нужно:** добавить bevel ~0.5-1.0мм на верхней и нижней рёбрах каждого слоя (modifier Bevel → Width 0.001, Segments 2). Это даст:
- мягкие highlight'ы на свету (плита перестанет выглядеть бумажной)
- более реалистичный specular response от MeshStandardMaterial
- архитектор/дизайнер сразу видит «настоящую» плиту, а не CAD-mockup

Только верх/низ — боковые грани не фасочить (для inset эффекта они должны оставаться острыми).

### B. Material naming — убрать VAR_ префикс

Сейчас на body материал называется `VAR_body`, на topcoat — `VAR_topcoat`. В Three.js runtime я делаю поиск меша по имени, не по материалу, поэтому **сейчас работает**.

Но для будущей чистоты — переименуй материалы Blender так, чтобы они совпадали с именами мешей:

| Меш (имя объекта) | Текущее имя материала | Нужное имя материала |
|---|---|---|
| topcoat | VAR_topcoat | topcoat |
| body | VAR_body | body |
| mesh-layer | VAR_mesh-layer (?) | mesh-layer |
| membrane | (что есть) | membrane |
| primer | (что есть) | primer |
| substrate | (что есть) | substrate |

Префикс VAR_ был задуман для runtime-swap по материалам, но я делаю swap по имени меша — префикс не нужен.

### C. Микроварианты (опционально, ускоряет интерактивность)

Если есть желание — для terrazzo-* сделать 3 вариации (light/medium/dark) одного и того же материала, экспортнуть как разные .glb (например `terrazzo-cement-light.glb`, `terrazzo-cement-medium.glb`, `terrazzo-cement-dark.glb`).

Это даст возможность пользователю менять оттенок в dropdown — сейчас цвет меняется через JS lerp, а с твоими реальными вариациями было бы аутентичнее. **Не блокирующее, делать только если интересно.**

## Чего НЕ делать

- Не менять имена самих объектов (topcoat, body, mesh-layer, membrane, primer, substrate) — на них завязан JS-поиск.
- Не менять inset-логику (300, 299, 298... мм) — уже работает.
- Не пытаться запекать текстуры в GLB. Текстуры будут привозить отдельно через `textures-v3/<slug>/diffuse|normal|roughness|ao.jpg` — сейчас плиты идут с procedural fallback PBR (это норм, апгрейдим позже).
- Не делать LOD'ы. 10-13 КБ на плиту — уже идеально лёгкие.
