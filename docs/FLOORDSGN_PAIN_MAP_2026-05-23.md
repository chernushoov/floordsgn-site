# FloorDSGN — карта болей и направление развития (2026-05-23)

Цель (владелец): выявить ВСЕ боли всех, кто сталкивается с напольными покрытиями, и для каждой — решить или предложить решение. Ниже синтез 2 исследований + что у нас УЖЕ есть vs гэпы + дорожная карта.

## Кратко: где мы сильны, где дыры
- **Сильны (редкость для IL = моат):** нормы (ת״י466/EN1504/EN13813/DIN R-класс/HACCP/влажность), подбор системы под задачу, проверка готовности основания (substrate-check), сравнение, калькулятор, спека-PDF, энциклопедия проблем (14 статей).
- **Структурная проблема:** лучшие инструменты СПРЯТАНЫ — studio/substrate-check/decision-tool/visualizer/compare не в меню, не в sitemap, studio = noindex, инструменты дублируются и не связаны.
- **Главные дыры:** (1) всё на RU/EN — **нет иврита** = весь израильский рынок закрыт; (2) ничего ПОСЛЕ продажи (обслуживание/гарантия/уход = 0 страниц); (3) нет диагностики «ремонт или замена»; (4) нет TCO/стоимости владения; (5) нет BoQ/расхода материалов; (6) визуализация «в моём интерьере» — слабая.

## Боли по сегментам (топ, severity H)
**Архитекторы/дизайнеры:** спека в тендер (есть PDF, нужен DOCX-генератор по формату); CAD-детали (узлы/галтели/швы) — обещаны, нужен self-serve; «как будет выглядеть в МОЁМ интерьере» (гэп → визуализатор); «клиент винит меня, если пол подведёт» (→ гарантийное письмо на имя архитектора); R-класс под помещение (есть в матрице).
**Владельцы/девелоперы/FM:** стоимость владения за 10 лет TCO (гэп); простой объекта на время монтажа (частично); готово ли основание + скрытый бюджет на подготовку (есть substrate-check, добавить фото-загрузку); HACCP-соответствие (частично); хлориды у моря (Хайфа/Ашдод) едят бетон (статья → услуга-аудит); «пол уже сыпется — чинить или менять?» (гэп, ВЫСОКИЙ интент); гарантия/что её аннулирует (гэп); חוק המכר — обязательства по дефектам новостроя (частично).
**Домовладельцы:** микротопинг vs терраццо vs эпокси для дома (есть); треснет/пожелтеет/холодный/царапается (разрозненно → честный FAQ); **как ухаживать/мыть** (гэп, 0 страниц); тёплый пол совместим? (гэп); цена за мою квартиру (есть); насколько грязный/долгий монтаж в жилой квартире (частично); реальный образец (есть); «подрядчик не исчезнет?» (страница доверия).
**Подрядчики/аппликаторы:** BoQ — кг материала/праймера/сила на м² (гэп); pot-life/пропорции/темп-окно (гэп → field-card); жара IL >30°C убивает pot-life (гэп → сезонный планер).
**Основание (двигатель отказов):** влажность RH/CM — отказ №1 (есть, усилить); трещины/карбонизация/адгезия/ровность (есть); хлориды (есть → услуга).
**Жизненный цикл:** когда перекрывать (статья → таймер); уход без аннулирования финиша (частично); регистрация гарантии + напоминания (гэп = удержание/рефералы).

## Дорожная карта «куда развиваться» (по ROI)
1. **Консолидировать + показать инструменты.** Studio = единый хаб, втянуть substrate-check/decision-tool/visualizer, в меню + sitemap, снять noindex. Бесплатно, огромный рост конверсии и SEO (лучшие активы сейчас невидимы).
2. **Иврит + RTL.** Весь домашний рынок IL. Крупнейший рычаг выручки.
3. **Диагностика «ремонт или замена»** (фото/вопросы → причина → перекрыть/налить/менять + цена + простой). Самый высокоинтентный запрос, конкуренты игнорируют, прямой лид на выезд. Расширяет движок substrate-check.
4. **Хаб обслуживания + гарантии** (уход по системам + объяснение гарантии + скачиваемая карта ухода/образец гарантии). Сейчас 0. Владеет всей пост-продажей + апселл перекрытия.
5. **TCO/стоимость владения** (монтаж + цикл перекрытий + простой) — решает B2B-покупки, ни у кого нет.
6. **BoQ/расход материалов** (кг + цена на м²) — конвертит про/архитекторов.
7. **Спека+CAD генератор** (DOCX-блок + dwg/dxf) — запирает архитектора в тендере.
8. **IL-специфика:** прибрежный аудит хлоридов (EN1504), HACCP-пакет для пищёвки, жара/сезонный планер.
9. **Визуализатор «в вашем интерьере»** (см. отдельный план ниже).

## Моат (главная дифференциация vs IL-конкурентов)
**Единственный ивритский «движок израильских норм пола».** Никто — ни дилеры Sika, ни общие флоринг-сайты, ни локальные сервис-приложения — не переводит ת״י466/EN1504/EN13813/DIN R-класс/HACCP в «вот точная система, пирог, класс скольжения и тест основания, который легально нужен именно вашему объекту в Израиле». У нас это уже построено (RU/EN) — на иврите, консолидировано и проиндексировано это превращает маркетинг-сайт в де-факто справочник по полам Израиля и выигрывает архитекторов (авторов спек), а за ними — их проекты.

## Визуализатор «наши полы в вашем интерьере» — реалистичность
**Реально, фазами:**
- **Ф1 (доступно сейчас, бесплатно, без внешних сервисов):** загрузи фото комнаты → отметь 4 угла пола → накладываем нашу текстуру с перспективой и блендом (canvas/WebGL). Качество = понятный превью, не фотореал. + пресет-сцены (кухня/офис/шоурум/гостиная) для тех, у кого нет фото. Effort: дни.
- **Ф2 (идеал — фотореал «в один клик»):** фото интерьера → AI авто-определяет пол → фотореалистично подменяет на наш материал, сохраняя свет/перспективу. Технически реально (есть бесплатный SDXL/Kaggle pipeline + Pollinations; платные Replicate/Runway проще/качественнее, но по правилу — без платных без явного «ок на $X»). Риск: контроль «именно наш материал» + консистентность + время генерации. Это R&D-фаза.
- **Честно:** «фотореал в вашем интерьере в один клик» = достижимо, но это самая сложная часть; правильный путь — Ф1 сейчас (конвертит уже), Ф2 как «вау» следом.
