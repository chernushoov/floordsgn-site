# Blender — промт на сборку плитки-образца (тело системы) для конфигуратора FloorDSGN

**Дата:** 2026-05-23 · **Для:** Blender-MCP (AI) или человека-художника · **Полная спека:** см. `docs/BLENDER_3D_BRIEF_2026-05-19.md` (этот файл — исполняемый промт-выжимка).

> Как использовать: скопируй блок «ПРОМТ» ниже и дай его Blender-MCP (или художнику). Делается **по одной плитке на материал** — список материалов и толщины в таблице. Сначала сделай и согласуй ОДНУ (`epoxy`), потом остальные по образцу.

## КОНТЕКСТ (зачем)
Это интерактивный образец пола 300×300 мм на сайте (three.js r158, WebGL). Пользователь видит плиту в разрезе с подписанными слоями («пирог»), вращает, переключает виды Solid / Layers-explode / Top / Reset. Уровень доверия к 3D = уровень доверия к компании. Плита должна выглядеть как реальный образец материала, который кладут на стол в шоуруме.

**Важно (статус):** толщины слоёв в текущих GLB уже верные. Реальный пробел, ради которого делаем модель заново: **(1) проработанный торец/профиль, (2) правильная UV-развёртка под реальный размер фактуры, (3) реализм поверхности тела системы.** Не нормализуй всё к одной высоте — высота = сумме реальных слоёв.

## ПРОМТ (давать Blender-MCP / художнику)

«Построй в Blender один GLB-образец напольной системы **<SLUG>** — квадратную плиту 300×300 мм в плане, высота = сумме реальных слоёв (см. таблицу). Всё в миллиметрах, единицы Blender = метры, 1 мм = 0.001 м. Ось Y вверх, +Z к зрителю, +X вправо.

ИЕРАРХИЯ (имена обязательны буква-в-букву):
```
plateRoot            (Empty, origin в центре ВЕРХНЕЙ грани, координата 0,0,0)
├── topcoat          (верхний лак/sealer)
├── body             (ТЕЛО СИСТЕМЫ — главный слой)
├── mesh-layer       (армосетка — ТОЛЬКО если в таблице есть; иначе не создавать)
├── membrane         (мембрана/акуст. подслой — ТОЛЬКО если есть)
├── primer           (грунт)
└── substrate        (бетон/стяжка)
```
Все слои НИЖЕ y=0, уложены стопкой по реальной толщине, без зазоров. plateRoot origin — в центре верхней грани topcoat.

ГЕОМЕТРИЯ:
- Каждый слой — отдельный mesh, прямоугольный параллелепипед 300×300 мм × своя толщина.
- **Торец (видимый край):** по верхнему периметру topcoat мягкая фаска (bevel) 1.5–2 мм. Слои в разрезе чуть отступают «лесенкой» вниз (каждый ниже на ~0.3–0.5 мм от края), чтобы в Layers-explode читался профиль фанерованного образца. Без видимых seam'ов и n-gon'ов (только tris/quads).
- **ТЕЛО СИСТЕМЫ (body) — герой:** именно его видно сверху. Верхняя грань body должна быть готова под фотофактуру (см. UV). Для терраццо/резины НЕ моделируй крошку геометрией — её даёт текстура, но UV должен быть масштабирован под реальный размер зерна (см. ниже). Допустима лёгкая микронеровность (bump через текстуру движком), геометрию не утяжелять.

UV (критично для реализма):
- 2 канала UV. UV1 — для diffuse/normal/roughness. UV2 — для AO (three.js r158 читает AO из uv2).
- Box/cube-проекция, острова прямоугольные, без растяжения.
- **Масштаб UV тела под реальную фактуру:** terrazzo — один «камень» крошки 4–18 мм должен читаться реально (tile ≈ 1.5–2× размера плитки), EPDM-резина 1–4 мм — мельче, микроцемент — почти бесшовно. То есть UV body подгоняется под размер зерна материала, а не «растянуть фото на 300 мм».

МАТЕРИАЛЫ (слоты, имена точно):
- topcoat → материал `VAR_topcoat` (префикс VAR_ обязателен — JS свапает по нему)
- body → `body`, mesh-layer → `mesh-layer fibreglass`, membrane → `membrane`, primer → `primer`, substrate → `substrate`
- PBR: MeshStandardMaterial (metalness/roughness). Текстуры НЕ встраивать в GLB и НЕ запекать свет — движок подгрузит текстуры по slug и сам даёт HDR-освещение. В Blender назначь временный плейсхолдер только для проверки UV.

ЗАПРЕТЫ: не встраивать текстуры (embedded) в GLB; не запекать освещение; не добавлять анимацию/арматуру/физику/shapekeys; не ставить логотипы Sika; subdivision не выше уровня 1; не менять имена; не оставлять n-gon'ы.

ЭКСПОРТ: glTF 2.0 binary (.glb), один файл `<SLUG>.glb`, текстуры отдельно (images_embedded=0), цель <500 КБ.»

## ПРИЁМКА (как проверить готовую плиту)
1. Имена объектов/материалов точно по списку (иначе плита не загрузится в JS).
2. Высота = сумма слоёв (не нормализована к 26 мм). Толщины из таблицы.
3. Торец с мягкой фаской 1.5–2 мм; в Layers-explode читается аккуратный профиль.
4. 2 канала UV; AO в uv2; масштаб UV тела под реальный размер фактуры.
5. GLB <500 КБ, без embedded-текстур, без n-gon'ов.
6. Поставка: `<SLUG>.glb` + `_BLEND_NOTES.md` (что сделано) + 1 рендер Eevee для глаза.
