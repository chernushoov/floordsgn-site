## SiteSucker settings — рекомендации

```
General:
  Limits: depth 4, file size max 50 MB per file
  File types: HTML, PDF, JPG, PNG, WEBP, MP4 (video allowed для project galleries)
  Pause: 1-2s between requests (вежливость к серверам)

Paths:
  Filter: Stay on host (не уходить во внешние сайты)
  Skip: cookies, analytics, social-widgets

Cookies:
  Disable (мы не залогинены, только публичный контент)

User-Agent: SiteSucker Pro default (некоторые сайты блокируют, тогда меняем на Safari UA)
```

```
~/Downloads/sitesucker/brands/topciment/
├── *.html  →  парсю в structured JSON: product name / type / TDS link / IL distributor
```

## Что НЕ скачиваем

- **Pinterest / Instagram** — robots.txt запрещает + контент chaotic
- **Google Images** — тоже запрещено
- **Houzz / Behance** — копирайт мутный, designer-uploaded
- **AliExpress / B2B каталоги типа Made-in-China** — мусорный signal-to-noise

Для inspiration фото используем Poly Haven / AmbientCG / Unsplash (CC0).
