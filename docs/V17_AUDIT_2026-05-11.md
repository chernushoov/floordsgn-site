## Bleed cleanup

Чисто. Контролы terrazzo-only (`aggregate`, `aggregateSize`, `accents`, `strips`, `sargelPattern`, `multiZone`) присутствуют **только** в `terrazzo` и `terrazzo-light`. В epoxy / microtopping / concrete-decorative / rubber / mma / pu-cement / parquet — отсутствуют.

## Найденные проблемы

### P1 — Stale inline fallback в enhance.js
`enhance.js:400-402` — inline fallback-конфиг для terrazzo не содержит `aggregateSize` и `crackBridging`, которые есть в `materials.config.json:90-100`. Если fetch конфига упадёт, эти контролы пропадут.

**Фикс**: дополнить fallback массив `['color','aggregate','aggregateSize','accents','strips','sargelPattern','multiZone','finishSlider','crackBridging','thickness']`.

### P2 — Минор: цвет узора саргели прибит к id полосы
`enhance.css:4837-4843` — цвета внутреннего grid/diagonal жёстко привязаны (brass4→#b8902a, alu4→#cdd0d4, black6→#1a1a1a). Если когда-нибудь поменять id полос — узор останется в старом цвете. Не блокер.
