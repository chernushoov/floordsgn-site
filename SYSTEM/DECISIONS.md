# DECISIONS — FloorDSGN Site

_Журнал ключевых решений (дата | решение | почему)_

---

## 2026-02-18 | Принят Meltbot OS
**Решение:** Развернуть Meltbot OS для управления проектом.
**Почему:** Нужен структурированный процесс контроля и наполнения контентом.

## 2026-02-18 | Vanilla JS без фреймворков
**Решение:** HTML/CSS/JS без React/Vue/Angular.
**Почему:** Максимальная скорость загрузки, простота деплоя через Netlify, нет зависимостей.

## 2026-02-18 | Decap CMS как headless CMS
**Решение:** Git-based CMS (Decap) вместо WordPress или Contentful.
**Почему:** Контент хранится в git, деплой автоматический через Netlify, бесплатно.

## 2026-02-18 | Приоритет на лиды, не на красоту
**Решение:** Любые изменения оцениваются по влиянию на конверсию.
**Почему:** Сайт = инструмент продаж, не портфолио дизайнера.
