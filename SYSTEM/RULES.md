# RULES — FloorDSGN Site

## Технические правила
1. Никаких фреймворков — только vanilla HTML/CSS/JS
2. Все тексты через translations.js — никаких хардкодных строк
3. RTL корректно работает для HE и AR
4. Контент редактируется ТОЛЬКО через Decap CMS (git-based) или прямой коммит в /content
5. Никаких правок в production файлах без теста в dev

## Контентные правила
6. Публикация material/blog/project → только через CMS схему из admin/config.yml
7. Изображения → только оптимизированные (WebP, сжатые)
8. Все SEO-поля (title, description, OG) обязательны при создании страниц

## Definition of Done
- Страница/контент: отображается корректно на всех 4 языках + RTL ✓
- Форма: заявка приходит на email ✓
- Деплой: Netlify build green ✓

## Что нельзя
- Ломать quiz-воронку (это главный источник лидов)
- Удалять или переименовывать content/ файлы без понимания последствий
- Деплоить JS-изменения без проверки в браузере
