образцы

Физические образцы 100×100 мм

Кусок реального материала с тех. описанием для презентации клиенту. Бесплатно для проектов от 50 м². Доставка по Израилю 5 дней.

Что входит: образец + buildup + slip class + палитра альтернативных аггрегатов + ориентир по цене на ваш объём.

документы

Спецификация под ваш стандарт

Полные Sika TDS, EPD (ISO 14025), DIN 51130 slip-class certificates, EU 10/2011 для food-zone. Готовый pack для projects-документации.

Что входит: TDS PDF + EPD + slip-class report + system warranty letter в формате под ваше техзадание.

CAD

CAD-детали под проект

Сечения cove-base, divider-strips, expansion joints, переходов между зонами под вашу планировку. dwg / dxf / pdf.

Что входит: 8–15 типовых деталей под вашу систему + custom-детали для нестандартных мест за 5 рабочих дней.

контроль

Авторский надзор архитектора

Вы согласовали палитру терраццо в студии — мы покажем результат на тестовом 5 м² перед основной заливкой. Изменения вносятся до старта объекта, не после.

Что входит: mock-up 5 м² на согласование + авторский надзор на каждом ключевом этапе + photo-отчёт ежедневно.

named

Named architects на проектах

Ваше имя как архитектора публикуется на странице проекта в нашем portfolio (с вашего согласия). Лояльность реальной работы — лояльность ссылок.

Что входит: упоминание архитектора + студии + photo-credit на /projects/{slug} + публикация на нашем Instagram @floor.dsgn.

сертификация

Сертифицированный installer Sika

FloorDSGN — сертифицированный applicator Sika. Только мы можем оформить full Sika system warranty (5–10 лет). Не subcontractor "под Sika", а реальный лицензиат.

Что входит: Sika system warranty letter на ваш проект + поддержка от Sika tech-team при сложных задачах.
