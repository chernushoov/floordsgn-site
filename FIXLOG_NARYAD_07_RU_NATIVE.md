## 1. Задача (наряд)

Поднять RU с «машинного огрызка» до уровня носителя-инженера. RU — стратегический клин (на рынке IL русскоязычный премиум не обслуживает никто). 6 подзадач:

1. Убрать RU-огрызки («Краткая RU-сводка», «Полный EN-вариант выше») → полный перевод тела.
2. Убить рунглиш (англ. основа + кириллич. окончание = хард-фейл).
3. 4 флагманские энциклопедии RU-only с мёртвым EN-тогглом → залочить RU / закрыть EN.
4. RU «Back to Library» + стрэй-английские заголовки внутри RU → перевести.
5. «Меда декоративи» (иврит-транслит) → реальный русский термин.
6. Структурный i18n где надо.

## 2. Решения (durable)

| Вопрос | Решение | Почему |
|---|---|---|
| Флагманы: добавить EN-тело vs залочить RU | **Залочить RU + скрыть мёртвый EN-тоггл** | Additive-only, без фабрикации EN-контента. EN-тела — отдельный будущий пасс. |
| Как скрыть EN-тоггл (он в общем хедер-партиале) | **Per-page инлайн-скрипт** на 4 флагманах (форс RU + `display:none` на EN-кнопке, глобальный язык-преф не меняем) | Не де-партиалить общий хедер, переживает `build-partials`. |
| «Back to Library» | RU-блок → **«Назад в библиотеку»**; EN-блок остаётся английским | Переводим только внутри `data-lang-block="ru"`. |
| «Меда декоративи» | → **«декоративный литой бетон»** | Реальный технический термин вместо иврит-транслита. |
| Терминология | микроцемент / микротопинг / наливной пол / стяжка / затирка / грунт / заполнитель / пропитка-силер / сопротивление скольжению … | Профессиональная, не калька. |
| Стандарты (ICRI/DIN/ASTM/EN/ISO/ת״י), бренды, SKU, химия, единицы | **Оставлены как есть** | Не транслитерируются. |
