Floor Tender BOQ Template

May 2026 · 7 min read

Every tender that delivered an actually-working floor had the same eleven line items. Most tenders that delivered failed floors had only three or four — usually combined into a single "supply and install epoxy" line that hid the prep, the broadcast spec, and the joint detail. This page is the practical BOQ template for an industrial-grade resin floor procurement: eleven lines, each with spec language, unit of measure, and the verification check that lets you reject a substandard submission. Substitute system class as needed (PU-cement, epoxy SL, MMA), but the line structure stays the same.

Worked example: 800 m² heavy-duty epoxy quartz broadcast on a logistics warehouse with 3 t reach-truck load. Substitute project numbers and system as needed.

What to reject in a submission

Five common patterns indicate the submission cannot deliver a working floor and should be returned for revision.

  • Single line "supply and install epoxy at ₪X/m²". Hides substrate prep, broadcast quality, joint detail. Reject and request itemisation per the eleven-line structure.
  • Substrate prep line missing or below ₪15/m². Implies surface-clean only, not mechanical prep. Sets up year-two delamination.
  • Pull-off test line missing. No QA mechanism to verify the install before final payment.
  • Generic SKU "epoxy SL" without manufacturer + product. Allows substitution at applicator's discretion. Specify named SKU minimum + equivalent-or-better acceptance criteria.
  • Warranty term not specified or shorter than manufacturer's published. Indicates applicator hedge — make explicit by asking for warranty term breakdown.

Substitution for other system classes

  • PU-cement 6–9 mm kitchen: Lines 4 + 5 collapse into single PU-cement system pour. Line 3 primer typically integral. Line 6 sealer often integral. Line 9 cove is non-negotiable. Material cost +40–60% vs epoxy quartz.
  • MMA fast-cure: Lines 4 + 5 + 6 collapse into MMA system pour. Line 3 primer MMA-specific. Pot life dramatically shorter — pour windows tight. Material cost +30% vs PU-cement.
  • Microtopping decorative 2–3 mm: Lines 5 (broadcast) + 8 (joint as substrate-replicated) omitted. Line 6 sealer is critical for stain resistance. Line 9 cove only if hygiene zone. Material cost –60% vs heavy-duty epoxy.
  • Polished concrete: Lines 3–6 replaced with densifier application + diamond polishing. Line 7 anti-slip via texture density. Line 8 saw-cut joints integral to slab.

Final read

Eleven lines, named SKU, named test method, named verification check. The BOQ template is the procurement-side enforcement mechanism for the warranty triangle: if a line is omitted, the warranty cannot trigger. Use this as the starting point and substitute system class as needed; the line structure is invariant across resin and cementitious systems. Шаблон тендерной сметы (BOQ) на пол

Май 2026 · 7 мин чтения

У каждого тендера, по которому в итоге получился действительно работающий пол, были одни и те же одиннадцать позиций сметы. У большинства тендеров, давших дефектный пол, было всего три-четыре позиции — как правило, слепленных в одну строку «поставка и устройство эпоксидного пола», которая прятала подготовку основания, спецификацию засыпки и узел деформационных швов. Эта страница — практический шаблон сметы (BOQ) для закупки промышленного смоляного (полимерного) пола: одиннадцать позиций, у каждой — формулировка спецификации, единица измерения и контрольная проверка, по которой можно отклонить некачественное предложение. Класс системы при необходимости заменяйте (ПУ-цемент, наливной эпоксидный пол, ММА), но структура позиций остаётся той же.

Рабочий пример: 800 м² эпоксидного пола особой стойкости с засыпкой кварцем на логистическом складе с нагрузкой от ричтрака 3 т. Подставьте свои проектные цифры и систему по необходимости.

Что отклонять в предложении

Пять частых признаков указывают, что предложение не сможет дать работающий пол, и его следует вернуть на доработку.

  • Одна строка «поставка и устройство эпоксидного пола по ₪X/м²». Прячет подготовку основания, качество засыпки, узел швов. Отклонять и требовать разбивку по структуре из одиннадцати позиций.
  • Позиция подготовки основания отсутствует или ниже ₪15/м². Подразумевает только очистку поверхности, а не механическую подготовку. Закладывает отслоение на втором году.
  • Нет позиции испытания на отрыв. Отсутствует механизм контроля качества для проверки укладки до финальной оплаты.
  • Обезличенный артикул «наливной эпоксидный» без производителя и продукта. Допускает замену на усмотрение подрядчика. Указывайте конкретный артикул как минимум + критерий приёмки «равноценный или лучше».
  • Срок гарантии не указан или короче заявленного производителем. Признак подстраховки подрядчика — проясните, запросив разбивку гарантийных сроков.

Замена для других классов систем

  • ПУ-цемент 6–9 мм, кухня: позиции 4 и 5 сворачиваются в единую заливку системы ПУ-цемента. Грунт по позиции 3, как правило, интегральный. Пропитка по позиции 6 часто интегральная. Галтель по позиции 9 обязательна. Стоимость материала +40–60% относительно эпоксидного пола с кварцем.
  • ММА быстрого отверждения: позиции 4, 5 и 6 сворачиваются в заливку системы ММА. Грунт по позиции 3 специфичен для ММА. Жизнеспособность заметно короче — окна для заливки сжатые. Стоимость материала +30% относительно ПУ-цемента.
  • Декоративный микротопинг 2–3 мм: позиции 5 (засыпка) и 8 (шов как воспроизведённый по основанию) исключаются. Пропитка по позиции 6 критична для устойчивости к пятнам. Галтель по позиции 9 только в гигиенической зоне. Стоимость материала –60% относительно эпоксидного пола особой стойкости.
  • Полированный бетон: позиции 3–6 заменяются нанесением упрочнителя (силиката) + алмазным шлифованием. Противоскольжение по позиции 7 — за счёт плотности текстуры. Швы по позиции 8 нарезаются и интегрированы в плиту.

Итог

Одиннадцать позиций, конкретный артикул, конкретный метод испытаний, конкретная контрольная проверка. Шаблон сметы (BOQ) — это механизм принуждения со стороны закупки для гарантийного треугольника: если позиция пропущена, гарантия не сработает. Используйте как отправную точку и заменяйте класс системы по необходимости; структура позиций неизменна для смоляных и цементных систем.
